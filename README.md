# 🐛 꿈틀꿈틀 핀란드 준비 앱

핀란드 연수·여행을 준비하는 선생님들(20대 후반~30대)을 위한 영어 학습 앱이에요.
설치 없이 휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 일반 앱처럼 쓸 수 있어요(PWA).

## 주요 기능

| 기능 | 내용 |
| --- | --- |
| 📚 매일 영어 표현 30개 | 아침·점심·저녁에 10개씩 학습. 중상급(B1~B2+) 수준의 구동사, 관용 표현, 교육 현장 전문 어휘 |
| 🔊 발음 확인 | 원어민 발음 듣기(보통/천천히), 예문 듣기, 🎤 **따라 말하기**(음성 인식으로 발음 일치도 확인) |
| 🧳 여행 영어 회화 | 공항·호텔·식당·교통·쇼핑·학교 방문·스몰토크·응급 상황 8가지 대화를 읽어 줌. 문장별 듣기, 전체 대화 이어 듣기, 한국어 해석 켜고 끄기 |
| 📰 하루 하나 핀란드 교육뉴스 | 인터넷에서 매일 핀란드 교육 기사를 자동으로 가져와요. 헤드라인을 누르면 **요약 / 전문(영어)** 중에서 골라 읽기. 전문은 읽어 주기 지원, 핵심 단어 정리 |
| ✈️ 출발 D-day | 홈 화면에 핀란드 출발까지 남은 날 표시 (기본 2027년 1월 8일, 설정에서 변경) |
| 💪 응원의 말 | 연습을 시작하기 전에 응원 메시지 |
| 🎉 수고의 말 | 연습을 마치면 수고 메시지와 축하 효과 |
| 📈 기록 | 연속 학습일, 배운 표현 수, 오늘 할 일 진행률 (기기에 저장) |
| ⚙︎ 설정 | 미국·영국·호주식 발음, 목소리 선택, 말하기 속도 조절 |

- 단어는 날짜에 따라 자동으로 바뀌어요. 아침·점심·저녁 단어장은 각 100개이고, 10일 주기로 순서를 섞어서 반복해요.
- 뉴스는 아래 "교육 뉴스 자동 수집"에서 설명한 방식으로 매일 새로 가져와요. 실시간 뉴스가 없을 때를 위해 핀란드 교육에 관한 읽기 자료 14편("핀란드 교육 이야기")도 앱에 들어 있어요.
- 인터넷 없이도 열려요(서비스 워커 캐시).

## 휴대폰에서 사용하기

1. 이 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
2. `main` 브랜치에 반영되면 `https://<사용자명>.github.io/kkumteulkkumteul/` 주소로 배포돼요.
3. 휴대폰에서 주소를 열고 홈 화면에 추가해요.
   - **아이폰**: 사파리 → 공유 버튼 → "홈 화면에 추가"
   - **안드로이드**: 크롬 → ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"

> 발음 듣기는 기기에 설치된 음성(TTS)을 사용해요. 따라 말하기(음성 인식)는 안드로이드 크롬과 최신 iOS 사파리에서 동작해요.

## 교육 뉴스 자동 수집

`.github/workflows/news.yml`이 **매일 한국 시간 오전 6시**에 `scripts/fetch-news.mjs`를 실행해 `data/live-news.json`을 갱신하고, 사이트를 다시 배포해요.

1. **RSS에서 기사 찾기**: `scripts/news-sources.json`에 적힌 Yle News, Helsinki Times, Google News에서 교육 관련 키워드(school, teacher, curriculum …)가 들어간 새 기사를 골라요.
2. **본문 가져오기**: 기사 페이지에서 본문을 추출해 앱의 "전문" 탭에 보여 줘요. 본문을 못 가져온 기사는 "원문 기사 보기" 버튼으로 열어요.
3. **한국어 요약 (선택)**: 저장소 **Settings → Secrets and variables → Actions**에 `ANTHROPIC_API_KEY`를 등록하면 Claude가 한국어 제목, 3~4문장 요약, 핵심 단어 5개를 만들어요. 등록하지 않으면 영어 요약(본문 앞부분)만 보여 줘요.
4. **오늘 기사가 없을 때**
   - 최근 10일 안에 새 기사가 없으면 Google News에서 **최근 1년 안의 지난 기사** 중 아직 저장하지 않은 기사를 찾아와요.
   - 그래도 없으면 앱이 저장된 지난 뉴스를 날마다 돌아가며 "지난 뉴스 다시 보기"로 보여 줘요.
   - 저장된 뉴스가 하나도 없으면 "핀란드 교육 이야기"를 보여 줘요.

바로 한 번 실행하려면 **Actions → Update Finnish education news → Run workflow**를 누르세요. 첫 실행 때는 기사 3개를 가져와요.

> ⚠️ 가져온 기사 본문은 공개된 GitHub Pages 사이트에 그대로 올라가요. 기사 저작권은 각 언론사에 있으니, 앱 주소는 연수에 함께 가는 선생님들끼리만 공유하는 것을 권해요. 본문을 저장하지 않으려면 `news-sources.json`에서 `fullText`를 `false`로 바꾸면 돼요(요약과 원문 링크만 남아요).

## 내 컴퓨터에서 실행하기

```bash
npm install
npm start          # 브라우저에서 http://localhost:8080 열기
npm run news       # 교육 뉴스 한 번 가져오기 (data/live-news.json)
```

## 내용 고치기

빌드 과정 없이 파일만 고치면 돼요.

| 파일 | 내용 |
| --- | --- |
| `js/data/words.js` | 아침·점심·저녁 단어장 (`[영어, 뜻, 예문]`) |
| `js/data/travel.js` | 여행 회화 상황별 대화문과 표현 |
| `js/data/news.js` | 핀란드 교육 이야기 (실시간 뉴스가 없을 때 사용) |
| `scripts/news-sources.json` | 뉴스를 가져올 RSS 주소와 교육 키워드 |
| `js/data/messages.js` | 응원의 말 / 수고의 말 |
| `js/app.js` | 화면과 기능 |
| `css/style.css` | 디자인 |

내용을 고친 뒤 `sw.js`의 `CACHE` 버전(`kkumteul-v1` → `kkumteul-v2`)을 올리면, 이미 설치한 휴대폰에도 새 내용이 반영돼요.

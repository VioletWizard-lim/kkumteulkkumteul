# 🐛 꿈틀꿈틀 핀란드 준비 앱

핀란드 연수·여행을 준비하는 선생님들(20대 후반~30대)을 위한 영어 학습 앱이에요.
설치 없이 휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 일반 앱처럼 쓸 수 있어요(PWA).

## 주요 기능

| 기능 | 내용 |
| --- | --- |
| 🧭 하단 탭 | 🏠 홈 · 📚 영어 공부(오늘 단어·여행회화·교육뉴스) · ✈️ 여행(일정·관광지·환율·날씨) · ⚙️ 설정. 영어 공부와 여행 탭은 마지막으로 본 화면을 기억해요 |
| 📚 매일 영어 표현 30개 | 아침·점심·저녁에 10개씩, 100일 동안 매일 새 표현(총 3,000개 이상). 중상급(B1~B2+) 수준의 구동사, 관용 표현, 교육 현장 전문 어휘 |
| 🔊 발음 확인 | 원어민 발음 듣기(보통/천천히), 예문 듣기, 🎤 **따라 말하기**(음성 인식으로 발음 일치도 확인) |
| 🧳 여행 영어 회화 | 공항·호텔·식당·교통·쇼핑·학교 방문·스몰토크·응급 상황 8가지 대화를 읽어 줌. 문장별 듣기, 전체 대화 이어 듣기, 한국어 해석 켜고 끄기 |
| 📰 하루 하나 핀란드 교육뉴스 | 인터넷에서 매일 핀란드 교육 기사를 자동으로 찾아 제목·요약을 한국어로 번역해요. 헤드라인을 누르면 **요약 / 전문** 중에서 고르고, 전문은 언론사 원문 페이지로 열어요(저작권 보호를 위해 본문은 저장하지 않음) |
| 🗺️ 추천 관광지 | 핀란드 15곳 · 체코 12곳. 겨울 여행 팁, 그곳에서 써먹는 영어 한마디(읽어 주기), 지도 링크, ♥ 가고 싶은 곳 담기, 나라별 기본 정보(통화·시차·팁·전압) |
| 📅 오늘 일정 | 구글 시트에 적은 여행 일정을 홈 화면에 표시(오늘 일정, 없으면 다가오는 일정). 일정 화면에서 날짜별 지도·번호 표시·이동 경로, 일정 사이 🚶 도보·🚗 차 이동 시간과 거리, 🚇 대중교통·도보·택시 구글 지도 길찾기 |
| 🌤️ 지금 날씨 | 홈 화면에 헬싱키·프라하·서울의 현지 시각, 날씨, 기온·체감 온도, 최고/최저, 해 뜨고 지는 시간과 낮 길이, 핀란드·체코 옷차림 팁 (Open-Meteo, 1시간마다 갱신) |
| 💱 오늘의 환율 | 홈 화면에 달러·유로·체코 코루나 → 원 실시간 환율(Coinbase 공개 API, 1시간마다 갱신)과 유럽중앙은행 기준환율 대비 등락. 실시간 환율이 안 되면 기준환율로 대체. 🎯 목표 환율을 정하면 그 아래로 내려갈 때 표시. "맘에 드는 가격이 나오면 트래블로그 카드에 넣어 놓기!" 안내 |
| ✈️ 출발 D-day | 홈 화면에 핀란드 출발까지 남은 날 표시 (기본 2027년 1월 8일, 설정에서 변경) |
| 💪 응원의 말 | 연습을 시작하기 전에 응원 메시지 |
| 🎉 수고의 말 | 연습을 마치면 수고 메시지와 축하 효과 |
| 📈 기록 | 연속 학습일, 배운 표현 수, 오늘 할 일 진행률 (기기에 저장) |
| ⚙︎ 설정 | 미국·영국·호주식 발음, 목소리 선택, 말하기 속도 조절 |

- 단어장은 아침·점심·저녁 각 약 1,000개(총 3,000개 이상)예요. 앱을 처음 연 날이 1일차이고, 하루 30개씩 **100일 동안 매일 새 표현**이 나와요. 출발일(2027년 1월 8일)까지 충분해요. 100일이 지나면 순서를 다시 섞어 복습해요.
- 뉴스는 아래 "교육 뉴스 자동 수집"에서 설명한 방식으로 매일 새로 가져와요. 실시간 뉴스가 없을 때를 위해 핀란드 교육에 관한 읽기 자료 14편("핀란드 교육 이야기")도 앱에 들어 있어요.
- 인터넷 없이도 열려요(서비스 워커 캐시).

## 휴대폰에서 사용하기

1. 이 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
2. `main` 브랜치에 반영되면 `https://<사용자명>.github.io/kkumteulkkumteul/` 주소로 배포돼요.
3. 휴대폰에서 주소를 열고 홈 화면에 추가해요.
   - **아이폰**: 사파리 → 공유 버튼 → "홈 화면에 추가"
   - **안드로이드**: 크롬 → ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"

> 발음 듣기는 기기에 설치된 음성(TTS)을 사용해요. 따라 말하기(음성 인식)는 안드로이드 크롬과 최신 iOS 사파리에서 동작해요.

## 일정 구글 시트 연결

1. 구글 시트 첫 줄에 `날짜 | 시작 | 끝 | 일정 | 장소 | 주소 | 메모`를 적어요. (`날짜`, `일정`은 필수, `위도`·`경도` 열은 선택) 예시: `docs/schedule-template.csv`
2. 날짜는 `2027-01-09` 또는 `1/9`, 시간은 `09:30` 또는 `오후 2:00`. 같은 날 일정은 날짜 칸을 비워도 돼요.
3. **공유 → 링크가 있는 모든 사용자(뷰어)** 로 바꾸고 링크를 복사해요.
4. 기본 일정 시트는 `js/config.js`의 `scheduleSheetUrl`에 들어 있어서 모든 선생님 앱에 같은 일정이 나와요. 각자 다른 시트를 쓰려면 앱 **⚙️ 설정 → 📅 일정 구글 시트**에 붙여 넣어요.

- 주소는 OpenStreetMap(Nominatim)으로 위치를 찾고, 도보·차 이동 시간은 OpenStreetMap 경로 서버로 계산해요. 위치를 못 찾으면 시트에 주소를 더 자세히 적거나 `위도`·`경도`를 적어 주세요.
- 버스·트램·지하철 시간은 무료로 계산할 수 없어서 🚇 버튼으로 구글 지도 대중교통 길찾기를 열어요.
- 시트를 고치면 앱이 열릴 때(10분 간격) 새로 불러와요.

## 교육 뉴스 자동 수집

`.github/workflows/news.yml`이 **매일 한국 시간 오전 6시**에 `scripts/fetch-news.mjs`를 실행해 `data/live-news.json`을 갱신하고, 사이트를 다시 배포해요.

1. **RSS에서 기사 찾기**: `scripts/news-sources.json`에 적힌 Yle News, Helsinki Times, Google News에서 교육 관련 키워드(school, teacher, curriculum …)가 들어간 새 기사를 골라요.
2. **본문은 저장하지 않아요**: 저작권 보호를 위해 기사 본문은 저장하지 않고, 제목·짧은 요약·원문 링크만 저장해요. Google News 링크는 실제 언론사 주소로 바꿔서 "원문 기사 보기"로 바로 열려요. (`news-sources.json`의 `storeFullText`를 `true`로 바꾸면 본문을 저장할 수 있어요.)
3. **자동 번역 (API 키 필요 없음)**: 제목과 요약을 무료 번역(Google 번역 공개 주소, 안 되면 MyMemory)으로 한국어로 옮겨 저장해요. 번역 서비스가 막히면 영어만 저장하고, 다음 실행 때 다시 시도해요.
4. **더 자연스러운 한국어 요약 (선택)**: 저장소 **Settings → Secrets and variables → Actions**에 `ANTHROPIC_API_KEY`를 등록하면 Claude가 자연스러운 한국어 제목, 3~4문장 요약, 핵심 단어 5개를 만들어요.
5. **오늘 기사가 없을 때**
   - 최근 10일 안에 새 기사가 없으면 Google News에서 **최근 1년 안의 지난 기사** 중 아직 저장하지 않은 기사를 찾아와요.
   - 그래도 없으면 앱이 저장된 지난 뉴스를 날마다 돌아가며 "지난 뉴스 다시 보기"로 보여 줘요.
   - 저장된 뉴스가 하나도 없으면 "핀란드 교육 이야기"를 보여 줘요.

바로 한 번 실행하려면 **Actions → Update Finnish education news → Run workflow**를 누르세요. 첫 실행 때는 기사 3개를 가져와요.


## 내 컴퓨터에서 실행하기

```bash
npm install
npm start          # 브라우저에서 http://localhost:8080 열기
npm run news       # 교육 뉴스 한 번 가져오기 (data/live-news.json)
```

## 내용 고치기

빌드 과정 없이 파일만 고치면 돼요.

| 파일 | 내용 |
| --- | --- |
| `js/data/words.js`, `js/data/words-*.js` | 아침·점심·저녁 단어장 (`[영어, 뜻, 예문]`) |
| `js/data/travel.js` | 여행 회화 상황별 대화문과 표현 |
| `js/data/news.js` | 핀란드 교육 이야기 (실시간 뉴스가 없을 때 사용) |
| `scripts/news-sources.json` | 뉴스를 가져올 RSS 주소와 교육 키워드 |
| `js/data/places.js` | 핀란드·체코 추천 관광지 |
| `js/data/messages.js` | 응원의 말 / 수고의 말 |
| `js/app.js` | 화면과 기능 |
| `css/style.css` | 디자인 |

내용을 고친 뒤 `sw.js`의 `CACHE` 버전(`kkumteul-v1` → `kkumteul-v2`)을 올리면, 이미 설치한 휴대폰에도 새 내용이 반영돼요.
